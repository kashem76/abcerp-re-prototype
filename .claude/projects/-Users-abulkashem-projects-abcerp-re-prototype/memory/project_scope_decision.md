name: Scope Decision — Flat First, Plot Later
description: Product scope decision made 25 Aug 2026 — focus on flat/apartment development, plot/land development is a future module
type: project
---

Flat/apartment development is the current focus. All 23 spec docs and 297 user stories cover Type 1 (build building, sell apartments).

Plot/land development (Type 2 — develop land infrastructure, sell plots with installment plans) is deferred as a future module. Key differences: map-based inventory (not tower/floor/unit), time-based installments (not milestone-based), infrastructure BOQ (not building BOQ), balloting/cooperative schemes.

**Why:** Core flat workflow is 70% built. Plot is a distinct vertical. Better to complete flat fully before expanding.

**How to apply:** When prioritizing features, focus on apartment sales workflow. Don't design dual-type architecture yet. Plot-specific stories (from Doc 22 gap analysis) stay as "future module."

Target companies doing both (Bashundhara, Nakheel, Roshn) will use the flat module first; plot module added later.
